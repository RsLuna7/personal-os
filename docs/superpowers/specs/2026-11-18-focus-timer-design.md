# 专注计时设计

日期：2026-11-18
状态：已确认的决定来自使用者，其余为实现时的取舍（标注“我的取舍”）；范围收紧，先交付可用版本

## 目标

给 Kairos OS 加一个专注计时：开一轮专注，记下做了什么、用了多久，之后能看到今天做了什么、最近哪些天专注得多、这周时间花在哪些事上。

成功的标准：打开首页，一次点击就能开始上一次的那种专注；刷新、关掉标签页再打开，计时不丢；结束后在「专注」页看得到今天的记录、热力图和本周分布。

## 已确认的决定

| 事项 | 决定 |
| --- | --- |
| 计时方式 | 番茄钟（专注/休息时长可调，预设 25/5、45/10、50/10，可自定义；专注结束自动进入休息，休息结束提醒开始下一轮）和正计时（一直往上数，手动结束）都要 |
| 位置 | 首页角落一个常驻的小计时组件，不抢全局时间轴的位置；另有独立的「专注」页（`#/focus`）放记录和统计；顶栏导航行加入口 |
| 归类 | 自由标签，每次专注选一个；可输入新标签，也可从历史标签里补全；颜色从 Radix 色板自动分配并保持稳定；可选填一句备注 |
| 统计 | 今日记录列表 + 日历热力图（每天专注总分钟数）+ 本周按标签统计 |
| 数据 | 记录存在浏览器里，和现有规划数据一起导出/导入；数据版本 +1，写好迁移 |
| 风格 | 沿用技术栈（React + TS + Vite、shadcn/ui、Radix Colors 暖灰）、暖色纸感、顺滑过渡；不做暗色模式 |

## 不做

- 休息时间的统计（休息不计入任何统计）。
- 把专注挂到待办或板块上（标签是自由文字，和板块无关）。
- 跨设备同步、手机端适配、后台 Web Worker 计时。
- 统计的时间范围切换（热力图固定最近 26 周，按标签统计固定本周）。
- 在今日记录里手动补记一条专注。

## 1. 计时器行为

### 状态

计时中的状态不进规划数据，单独存在 `localStorage` 的 `personal-os:focus-run`（不进导出的备份，和界面偏好同理：它只对这个浏览器、此刻有意义）。

```ts
interface RunState {
  mode: 'pomodoro' | 'stopwatch'
  phase: 'focus' | 'break' | 'ready' // ready：休息结束，等着开始下一轮
  tag: string
  note: string
  focusMs: number // 番茄钟的专注时长；正计时为 0
  breakMs: number // 番茄钟的休息时长；正计时为 0
  startedAt: number // 当前阶段的开始时刻（毫秒时间戳）
  pausedAt: number | null // 正在暂停时，暂停开始的时刻
  pausedMs: number // 当前阶段已累计的暂停时长
}
```

- **只用时间戳算**：已用时间 = `(pausedAt ?? now) − startedAt − pausedMs`。没有任何地方靠定时器一秒一秒累加；`setInterval` 只负责“隔一会儿重新算一次并刷新界面”，后台标签页被降频只会让界面刷新变慢，不会让时间变错。
- **刷新或重开后恢复**：每次状态变化立即写入存储；启动时读出来，按当前时刻补算——专注阶段已经超过目标时长，就按“专注在它该结束的那一刻结束”补一条记录（`endAt = startedAt + pausedMs + focusMs`），再从那一刻起算休息，休息也过完了就停在 `ready`。关掉标签页期间时间照走。
- **补记不重复**：记录的 `id` 由开始时刻决定（`focus-<startedAt>`），同一轮在两个标签页里都补算时只会留下一条。
- **多标签页**：监听 `storage` 事件，另一个标签页改了计时状态，这边跟着更新。

### 操作

| 操作 | 效果 |
| --- | --- |
| 开始 | 选模式、标签（必填）、备注（选填），番茄钟再选时长；从现在起专注 |
| 暂停/继续 | 记下暂停开始的时刻；继续时把这段时间加进 `pausedMs`。专注和休息都能暂停 |
| 提前完成 | 只在专注阶段。按已用时间记一条（有效），回到空闲 |
| 放弃 | 不记录，回到空闲。点一下先变成“确认放弃”，3 秒内再点才生效 |
| 跳过休息 | 休息阶段或 `ready` 时结束这一轮，回到空闲 |
| 开始下一轮 | `ready` 时用同样的设置开始新一轮专注 |

- 番茄钟专注到点：自动记一条（`completed = true`），自动进入休息；休息到点：进入 `ready`，提醒开始下一轮，不会自动开始。
- 正计时：手动“完成”，记一条（`completed = true`）。
- “提前完成”的番茄钟记 `completed = false`：它是有效的专注，计入全部统计，只是没有跑满计划时长。
- **不足 1 分钟的专注不保存**（提前完成时给一条提示；到点完成的番茄钟最短 1 分钟，所以一定保存）。
- 番茄钟时长范围：专注 1–180 分钟，休息 1–60 分钟，输入越界时取边界值。

### 反馈

- 计时中浏览器标签页标题显示时间：番茄钟写剩余，正计时写已用，如 `24:31 · 专注 · Kairos OS`；休息写 `04:12 · 休息 · Kairos OS`；`ready` 写 `休息结束 · Kairos OS`；空闲时恢复原标题。暂停时标题前加“⏸”。
- 专注结束、休息结束时：发系统通知，播放一声轻提示音，页面上弹一条提示。系统通知第一次点“开始”时请求权限（只在权限还没决定、且设置里没关通知时请求）；被拒绝就不再发，不重复追问。补算出来的“很久以前”结束的阶段（超过 5 分钟）不再通知、不响，只更新状态。
- 提示音用 Web Audio 合成一个短的柔和音，不带音频文件。
- **设置**（「专注」页标题右侧的齿轮）：两个开关——“系统通知”“提示音”，默认都开。存在 `personal-os:focus-prefs`，同时记着上次用的模式、时长、标签，供首页组件一键开始。

## 2. 界面

### 首页角落组件

固定在首页右下角（`fixed`，只在 `#/home` 出现），首页内容底部多留一段空白，避免盖住最后一行。

- **空闲**：一个小胶囊，写“专注”和上次的设置（如 `25/5 · 学习`），点它直接开始；旁边的小箭头打开一个浮层，里面是完整的开始表单（模式、时长、标签、备注）。从没用过时，点胶囊就是打开这个浮层。
- **计时中**：一张小卡片——标签色点、标签名、大号时间、阶段名；按钮：暂停/继续、完成（专注阶段）、放弃；点标签名跳到「专注」页。
- **休息 / ready**：同一张卡片，换成休息的倒计时或“开始下一轮 / 结束”。

### 「专注」页（`#/focus`）

顶栏导航加“专注”，排在“今日”之后、“回顾”之前。页面结构沿用今日页：画布底色、1280 版心、白色圆角卡片、卡片外的标题行。

```
专注                                         今天 1 时 25 分 · 3 次  ⚙
┌ 计时 ──────────────────────┐┌ 今日记录 ─────────────────────┐
│       24:31                 ││ 14:05–14:30 ● 学习  整理错题  25分 │
│  ● 学习   番茄钟 25/5       ││ 10:00–10:50 ● 英语  六级阅读  50分 │
│  [暂停] [完成] [放弃]       ││                                   │
└─────────────────────────────┘└───────────────────────────────────┘
┌ 本周按标签 ────────────────┐┌ 最近 26 周 ───────────────────────┐
│ ● 学习  ███████  3时10分    ││  热力图（周一在上，每列一周）      │
│ ● 英语  ███      1时20分    ││                                   │
└─────────────────────────────┘└───────────────────────────────────┘
```

- 宽度 ≥ 1024 两列；窄一些上下排，顺序：计时、今日记录、本周、热力图。
- **计时卡**：空闲时是开始表单，计时中是大号时间和控制按钮；和首页组件共用同一套组件。
- **标签输入**：一个输入框，下面一行芯片。芯片是历史标签（按最近使用排序，最多 8 个）；输入时只留包含输入内容的；点芯片填入，`Tab` 补全第一个以输入开头的标签；输入新的就是新标签。标签最长 20 个字。
- **今日记录**：今天（本地日期）开始的记录，新的在前；每行是起止时间、标签色块、备注、时长；悬停（或键盘聚焦）出现“改”和“删”。“改”把这一行变成标签 + 备注的输入，回车保存、Esc 取消；“删”走现有的撤销条。没有记录时写“今天还没有专注记录”。
- **本周按标签**：本周一到周日（本地），每个标签一行：色点、名字、横条（宽度按占本周总时长的比例，最长的标签占满）、时长。没有记录时写“本周还没有专注记录”。
- **热力图**：最近 26 周，周一在上，每列一周；每格是这一天的专注总分钟数，分五档着色（0 / 1–29 / 30–59 / 60–119 / ≥120 分钟，橙色色带从浅到深，0 用中性灰）；今天之后的格子不画；格子随卡片宽度伸缩、始终是正方形，任何宽度下都放得下 26 周，不横向滚动；每格有悬停提示“11月18日 周三 · 85 分钟”，同样的文字写进 `aria-label`；上方标月份，左侧标周一、周三、周五。
- 标签颜色：用标签文字做稳定哈希，取八条板块色带之一，同一个标签永远同色（不存储）；八种颜色里标签多了会撞色，可以接受。

### 动效

沿用现有节奏：150–250 毫秒缓出；开始表单与计时视图之间淡入切换；热力图格子和统计条的颜色、宽度有过渡；系统开启“减少动态效果”时全部关闭（全局已有这条规则）。

## 3. 数据

`AppData` 增加 `focusSessions: FocusSession[]`，`schemaVersion` 从 5 升到 6。

```ts
interface FocusSession {
  id: string
  mode: 'pomodoro' | 'stopwatch'
  tag: string // 1–20 个字
  note: string // 最多 200 个字，可空
  startAt: string // ISO 时间
  endAt: string // ISO 时间，不早于 startAt
  focusMs: number // 扣掉暂停后的专注时长，整数，≥ 60000，且不超过 endAt − startAt
  completed: boolean // 番茄钟跑满、或正计时手动完成；番茄钟提前完成为 false
}
```

- **校验**：id 和其他实体一起查重；上面各字段的范围。
- **迁移 `v5ToV6`**：补空的 `focusSessions: []`；升级前按现有方式把旧数据备份到 `personal-os:data:backup-v5`。
- **store**：`addFocus(session)`（id 已存在则忽略，用于补算去重）、`updateFocus(id, { tag, note })`（标签空则不生效）、`removeFocus(id)`；每个是一步撤销，和其他数据一样。
- **导出、导入**：整个 `AppData` 一起走，加字段即可。
- **示例数据**：加几天的记录，载入示例后热力图和本周统计不空。
- **统计归属**：记录算在 `startAt` 的本地日期那一天；跨零点的一轮不拆分（我的取舍）。

## 4. 代码结构

```
src/features/focus/
  timer.ts          纯函数：已用/剩余、补算（advance）、生成记录
  stats.ts          纯函数：今日记录、热力图、按标签聚合、标签颜色、时长格式
  focusStore.ts     计时状态（Zustand）+ 存储 + 设置
  alerts.ts         系统通知、提示音
  FocusRuntime.tsx  常驻：定时刷新、补算、改标题、发提醒
  StartForm.tsx / TagInput.tsx / TimerPanel.tsx
  FocusWidget.tsx   首页角落组件
  FocusPage.tsx     「专注」页：今日记录、本周、热力图、设置
```

边界沿用现有约定：`timer.ts`、`stats.ts` 是纯函数，不依赖 React 和存储，单独测试；界面只读数据、发出意图。

## 5. 体积

脚本总量上限 200 KB（gzip），做之前是 192.2 KB。实现后是 199.4 KB，勉强装下，上限不动；之后再加功能需要先腾出体积（比如按路由拆分代码）或重新定上限。

## 6. 测试

按仓库现有约定：Vitest + Testing Library，测试文件放在被测文件旁边，先写失败的测试。

- **`timer.ts`**：已用时间（含暂停中、暂停后继续）；剩余与到点；补算——专注刚过期、专注期间暂停过、专注和休息都过期、休息中途；专注阶段在暂停时不会到点；到点记录的 `endAt` 是它该结束的那一刻；不足 1 分钟不产生记录；提前完成 `completed = false`；记录 id 稳定。
- **`focusStore.ts`**：开始、暂停、继续、提前完成、放弃、跳过休息、开始下一轮；状态写入存储，重新加载能恢复（含“关掉很久后再打开”）；存储里是坏数据时忽略；另一个标签页写入时跟随；不足 1 分钟不保存。
- **数据层**：`v5ToV6` 迁移和备份；校验拒绝坏记录；`addFocus` 去重、`updateFocus`、`removeFocus`、撤销；导出再导入保留记录；示例数据通过校验。
- **`stats.ts`**：热力图（周对齐、今天之后不画、档位边界、跨零点按开始日期、本地时区）；本周按标签（周边界、同标签合并、排序、占比）；今日记录；标签颜色稳定且在色板内；历史标签排序。
- **界面**：导航有“专注”并能打开；开始、暂停、完成后今日记录出现；改标签/备注、删除并撤销；首页组件空闲/计时中；标题随计时变化；通知开关。
- 全部检查：`npm run lint && npm run typecheck && npm test && npm run build && npm run check:size`；界面在浏览器里看过 768、1024、1440 宽度。
