# 阶段和节点的“已完成”状态

## 目标

阶段（Phase）和节点（Milestone）可以标记为已完成。待办早就有 `done`，这里让时间线上的两类条目也能表达“做完了”。

## 数据

- `Phase.done: boolean`、`Milestone.done: boolean`，默认 `false`。
- 数据版本 3 → 4。迁移 `v3ToV4` 给每个阶段和节点补 `done: false`（已有 `done` 的保持原值）；`phases` / `milestones` 不是数组时原样放过，交给校验去拒绝。
- 升级流程不变：升级前把原数据存为 `personal-os:data:backup-v3`；导入第 1 到第 3 版备份会依次升级。
- 新建的阶段和节点是未完成；示例数据全部未完成。

## 界面

- 阶段和节点的编辑面板里加一个“已完成”开关，位置在“备注”之上。
- 时间线（`PhaseBlock`、`MilestoneDot`）：已完成的条目整体变淡（不透明度 0.55），阶段名称前带一个勾，节点用勾代替圆点；悬停提示和无障碍名称里写“已完成”；DOM 上带 `data-done`。
- “完成”不影响“进行中”“已结束”等按日期算出的状态，两者独立。
- 动态效果：只改不透明度，没有新增动画，因此不受“减少动态效果”影响；原有的出现和淡出动画照旧。
