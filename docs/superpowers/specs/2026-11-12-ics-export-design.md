# 导出日历（.ics）

## 目标

把应用里有日期的内容导出成标准的 iCalendar 文件，导入手机或电脑的日历应用里看。只出不进：不支持从 .ics 导入。

## 入口

“更多”菜单里，紧跟“导出备份”之后：**导出日历 (.ics)**。点一下直接下载 `personal-os-<今天>.ics`，并弹出提示“已导出日历，共 N 项”。它不是备份，不更新“上次导出”时间，也不影响备份提醒。

## 文件内容（`src/data/ics.ts`，纯函数 `buildIcs(data, now)`）

- 阶段：多日全天事件。`DTEND` 不含当天，和应用里阶段的半开区间一致，不用再减一天。待确认的阶段带 `STATUS:TENTATIVE`。
- 节点、有日期的待办：单日全天事件，`DTEND` 是后一天（跨月、跨年都正确）。
- 没有日期的待办跳过。已完成的待办，标题前加“✓ ”。
- `UID` 是 `<条目 id>@personal-os`，同一条目每次导出都一样，重复导入时日历会更新而不是重复。`DTSTAMP` 取导出时间（UTC）。
- 板块名写进 `CATEGORIES`；阶段和节点的备注写进 `DESCRIPTION`。不挂板块的待办没有分类。
- 文本转义（反斜杠、分号、逗号、换行），其余控制字符丢弃；每行最多 75 字节，超出折行（续行以一个空格开头，不拆开多字节字符）；行尾一律 CRLF。
- 数据为空时仍是一个合法的、没有事件的日历。
- 所有事件标为 `TRANSP:TRANSPARENT`（不占用忙闲时间）。

## 不做

不导出学期；不导出提醒（`VALARM`）；不做订阅链接。
