# 从模板添加

## 目标

新用户或新学期开始时，不用从空白一点点建：选一个内置模板和开始日期，一次铺开一套板块、阶段和节点。

## 行为

- 入口：“更多”菜单里的**从模板添加**，打开一个对话框。
- 对话框：选模板（单选）、选开始日期（默认今天）、预览将添加的内容（每个板块下的阶段和节点，日期就是实际会写入的日期）、“添加”或“取消”。开始日期不合法时“添加”不可点，预览提示先填日期。
- **追加，不覆盖**：新板块排在现有板块之后，颜色先用没人用过的，用完再循环；现有的板块、阶段、节点、学期、待办一概不动。同一个模板可以重复添加，得到互相独立的两份。
- 一次添加算**一步撤销**：成功后弹出提示“已从模板「…」添加 N 个板块”，带“撤销”，用现有的撤销机制。

## 模板（`src/data/templates.ts`）

日期都写成距开始日期的天数偏移，阶段的结束偏移不含当天（和应用里的半开区间一致）。

- **学期**（18 周）：板块 课程 / 考试 / 作业；阶段 开学适应、正课、期末冲刺、期中复习、期末复习、平时作业、大作业；节点 开学、期中考试、期末考试、大作业提交。
- **备考**（24 周）：板块 基础 / 强化 / 冲刺；阶段 基础阶段、强化阶段、冲刺阶段（首尾相接）；节点 基础摸底、第一次模拟考、第二次模拟考、正式考试。

## 实现

- 纯函数 `applyTemplate(data, template, startDate, newId)`：返回新数据，不改传入的数据；名称按 40 字上限截断。
- 状态：`addFromTemplate(template, startDate)` 走 `commit`，所以校验和撤销历史和其他修改一样。
- 界面状态 `templateOpen` 放在 `editorStore`，不进入数据和撤销历史。

## 不做

不支持自定义或导入模板；不在添加时同时建学期或待办。
