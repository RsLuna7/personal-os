# 今日页设计

日期：2026-11-12
状态：设计已口头确认，待审阅文档

## 目标

`#/today` 现在是占位页“待开发”。把它做成每天打开就用的地方：

- **待办的完整版**。首页的待办板块是精简版（最多 5 条、只能勾选），安排、补充、改期都在今日页完成。
- **每日打卡**。新增“习惯”，每天勾一下，看得到最近几天和连续记录。

成功的标准：早上打开今日页，不用跳到别的页面，就能把今天要做的事排好、做完勾掉、把该打的卡打完。

## 已定的选择

| 问题 | 结论 |
| --- | --- |
| 范围 | 待办完整版 + 每日打卡 |
| 习惯频率 | 每天，或指定星期几 |
| 打卡记录 | 只记做没做（不记数量、时长） |
| 布局 | 三栏：收件箱 \| 今天 \| 打卡，可以从收件箱拖进今天 |

## 1. 页面结构

```
11月12日 周四 · 第11周              待办 2/5 · 打卡 1/3
┌ 收件箱 ─────┐┌ 今天 ────────────────┐┌ 打卡 ──────────┐
│ 未安排 2     ││ 过期 1   全部移到今天 ││ ☑ 背单词 ■■■■■■■ 12天│
│ 明天 1       ││ 今天 4                ││ ☐ 健身   ■·■·■·  3次 │
│ 后天 …       ││ + 添加今天的待办      ││ 今天不用打 1 ▸       │
│ （接下来7天）││ 已完成 1 ▸            ││ + 新习惯             │
└──────────────┘└───────────────────────┘└──────────────────────┘
```

- **页头**：左边是日期、星期和学期周（复用时间线的 `weekLabel`：学期内写“第 N 周”，学期外不写）；右边是今天的进度“待办 已完成/总数 · 打卡 已打/应打”。总数只算今天的待办（含今天已完成的），不算过期。
- **宽度 ≥ 1024（`lg`）**：三栏并排，比例约 1 : 1.4 : 1，中间的“今天”最宽。
- **窄于 1024**：上下排，顺序是 今天 → 打卡 → 收件箱。窄屏不提供拖拽，靠每行的“→ 今天”按钮。
- 三栏都是首页同款卡片（`bg-(--bg-card)`、圆角 16、`--shadow-card`），标题用首页的 `SectionHeader`。

## 2. 今天（中间栏）

沿用首页待办板块的规则：

- 分组：过期（日期早的在前，右侧写原日期，标题旁有“全部移到今天”）→ 今天 → “已完成 N ▸”（可展开）。
- 勾选后在原位停留 `LINGER_MS`（1.5 秒）再收进“已完成”。
- 和首页不同：**不限条数**。

今日页额外有：

- **添加**：底部一行“+ 添加今天的待办”，点开是输入框，回车新增一条日期为今天的待办并清空输入框继续输入；Esc 或失焦且为空时收起。空标题不新增。
- **行内操作**：悬停（或键盘聚焦到该行）时，行尾出现三个图标按钮：
  - **推到明天**：日期改为明天；
  - **移回收件箱**：日期改为 `null`；
  - **删除**：删掉，可用现有撤销（Ctrl+Z 和 toast）恢复。
- **编辑**：点标题打开现成的 `TodoEditor`（`openEditor('todo', id)`），可以改名、改日期、挂板块。
- 每一步操作都是一次撤销。

空状态：今天和过期都没有时，显示一句“今天没有待办”加添加入口，不隐藏整栏（和首页不同，首页没东西就整块不显示）。

## 3. 收件箱（左栏）

内容：

- **未安排**：`date === null` 且没做完的待办，按创建时间排。
- **接下来 7 天**：日期在明天到今天 + 7 天（含）之间、没做完的待办，按天分组，组标题写“明天”“后天”，再往后写“11月15日 周六”。没有待办的日子不显示。

每一行：

- 勾选框、板块色条、标题（和今天栏同一个行组件）。
- 悬停时出现“→ 今天”按钮，点了日期改为今天。
- 点标题打开 `TodoEditor`。
- 收件箱里勾掉的待办同样停留 1.5 秒后消失（收件箱不显示已完成）。

拖拽（仅 `lg` 及以上）：

- 用指针事件实现，规则和日历一致：移动超过 `DRAG_THRESHOLD_PX`（4px）才算拖动，否则算点击。拖动时显示跟随指针的半透明行，目标栏高亮。
- 收件箱 → 今天栏：日期改为今天。
- 今天栏 → 收件箱：日期改为 `null`（未安排）。过期的待办也能拖回收件箱。
- 落在原来那一栏或栏外：什么都不做。
- 栏内不支持排序（待办没有顺序字段，本期不加）。

空状态：收件箱什么都没有时写“收件箱是空的”。

## 4. 打卡（右栏）

**今天该打的**：习惯的 `weekdays` 包含今天是星期几。每个习惯一行：

- 勾选框：勾上就是今天打了卡，再点取消。
- 名字，挂了板块的话前面有板块色条。
- **最近 7 天格子**（今天在最右）：打了卡的格子填满（板块色，没板块用中性色），没打的空心，那天不用打的格子变淡。格子可以点，补打或取消；比 7 天更早的不能改。习惯创建以前的日子也画成“不用打”。
- **连续记录**：右侧写“N 天”。N = 从今天往回数，每个该打的日子都打了的个数；不用打的日子跳过、不算断；今天该打但还没打，从昨天开始数，不算断；遇到第一个该打没打的日子就停。习惯创建之前的日子不算。N 为 0 时不显示。

**今天不用打的**：收成一行“今天不用打 N ▸”，展开后同样显示格子和连续记录，但没有今天的勾选框。

**新建和编辑**：

- 底部“+ 新习惯”打开习惯编辑面板（新建一个 `HabitEditor`，样式照 `TodoEditor`），字段：
  - 名字（必填，长度上限同其他名字）；
  - 频率：“每天”或勾选星期一到星期日（至少选一天；七天全选就等于每天）；
  - 板块（选填，同待办）；
  - 删除按钮（可撤销）。
- 点习惯名字打开同一个面板。

空状态：没有任何习惯时写“还没有习惯”加“+ 新习惯”。

## 5. 数据

新增类型：

```ts
export interface Habit {
  id: string
  name: string
  /** null 表示不挂板块 */
  laneId: string | null
  /** 哪几天要打卡，1 = 周一 … 7 = 周日，升序不重复，至少一个 */
  weekdays: number[]
  /** 打了卡的日期，升序不重复 */
  checks: ISODate[]
  /** ISO 时间：用来排序，也决定从哪天开始算 */
  createdAt: string
}
```

- `AppData` 增加 `habits: Habit[]`，`schemaVersion` 从 4 升到 5。
- 校验：id 和其他实体一起查重；`laneId` 必须指向存在的板块；`weekdays` 非空、在 1–7 之间、不重复；`checks` 里都是合法日期、不重复。
- 迁移 `v4ToV5`：补一个空的 `habits: []`。迁移前按现有方式备份到 `personal-os:data:backup-v4`。
- 删除板块时，挂在上面的习惯 `laneId` 改成 `null`（和待办一样）。
- 导出、导入、撤销都覆盖习惯（它们处理整个 `AppData`，加字段即可，需要测试确认）。
- 示例数据 `sample.ts` 加两三个习惯，带一些打卡记录。

store 新增操作（每个都是一步撤销）：

- `addHabit(input?: { name?, weekdays?, laneId? }): string`，默认每天；
- `updateHabit(id, patch)`：名字、星期、板块；
- `toggleCheck(id, date)`：打卡或取消；
- `removeHabit(id)`。

纯函数（新文件 `src/features/today/habits.ts`）：

- `isDue(habit, day)`：那天要不要打（看星期，且不早于创建日）；
- `streak(habit, today)`：按第 4 节的规则；
- `recentDays(habit, today, 7)`：最近 7 天每格的状态（打了 / 没打 / 不用打）。

纯函数（新文件 `src/features/today/inbox.ts`）：

- `inboxGroups(todos, today)`：未安排 + 接下来 7 天按天分组。

今天栏复用首页的 `homeTodos`，只是不用 `limitTodos`。

## 6. 和其他页面的关系

- 首页待办板块的链接“去日历 →”改成“去今日 →”，指向 `#/today`。代码注释里“以后是今日页”的说法一并更新。
- 日历页不变，仍然可以在那里安排和拖动待办。
- 首页暂时不显示打卡。

## 7. 不做

- 数量型打卡（如喝水 8 杯）、“每周任意 N 次”的频率。
- 提醒和通知。
- 把待办排进具体时间段。
- 习惯统计页、热力图。
- 待办的手动排序。
- 首页的打卡板块。

## 8. 测试

- **纯函数**：`isDue`（星期、创建日之前）、`streak`（今天未打不断、不用打的日子跳过、遇到漏打即停、创建日之前不算）、`recentDays`、`inboxGroups`（未安排、7 天边界、已完成不显示、分组标题）。
- **数据层**：习惯的增删改、`toggleCheck` 打卡和取消、删除板块后习惯 `laneId` 变 `null`、校验拒绝坏数据、`v4ToV5` 迁移和备份、导出再导入保留习惯、撤销。
- **页面**（Testing Library）：三栏都渲染；添加今天的待办；推到明天、移回收件箱、删除；“→ 今天”；拖拽（模拟指针事件从收件箱到今天栏，以及反向）；勾选后停留再收起；打卡、补打 7 天内的格子、7 天外不可点；新建、编辑、删除习惯；“今天不用打”收起；页头的进度数字。
- **窄屏**：栏的顺序为 今天 → 打卡 → 收件箱，不出现横向滚动；在浏览器里检查 375、768、1024、1440 四个宽度。
- 全部检查：`npm run lint && npm run typecheck && npm test && npm run build && npm run check:size`，脚本总量仍在 200 KB 以内。
