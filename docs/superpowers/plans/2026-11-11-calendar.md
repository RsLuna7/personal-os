# 日历月视图 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出顶栏“日历”这一页：月网格里显示阶段、节点、学期，并能拖选新建阶段、单击新建节点、拖动改期和改长度。

**Architecture:** 数据结构不变（版本仍是 2）。网格生成、阶段按周切段排槽、坐标换算成日期都是纯函数（`month.ts`、`layout.ts`、`drag.ts`），先测后写；拖动的状态机放在 `useCalendarDrag`，页面只发出修改意图，调用现有的 store 操作和编辑面板。路由参数扩展到 `calendar`（`YYYY-MM`）。

**Tech Stack:** React 19、TypeScript（strict）、Tailwind CSS v4、Zustand、Zod、Vitest + React Testing Library（与现有项目一致）。

**Spec:** `docs/superpowers/specs/2026-11-11-calendar-design.md`（上层：`2026-11-10-personal-os-v1-design.md`）

## Global Constraints

- 数据版本仍是 `CURRENT_SCHEMA_VERSION = 2`，不改 `schema.ts`，不加迁移。
- 周一为一周的开始；月网格显示完整的周，4 到 6 周；当月以外的日期淡化但可点、可拖到。
- 月份参数 `YYYY-MM`，年份限制在 1900 到 2100；缺失、格式不对、月份不存在或越界一律显示当前月，不报错。
- 日期只用 ISO 字符串和 `features/timeline/days.ts`、`snap.ts` 的整日数函数，不用带时区的 `Date` 做日期运算。
- 日历按**天**吸附，阶段最短 1 天（存储的 `end` 是半开区间，至少比 `start` 大 1 天）；时间线按周吸附的规则不变。
- 每个周行有 3 个槽；第 4 槽及以后不画；某天有项目落在第 4 槽及以后时，这一天的第 3 槽显示“+N 项”（N 是这一天落在第 3 槽及以后的项数）。
- 一次拖动只写入数据一次（一步撤销）；松手才写入；`Esc`、拖出网格后松手、被拖的项消失都取消。指针移动小于 4 像素算单击。
- 所有修改走现有 store 操作和 `PhaseEditor`、`MilestoneEditor`；`selection` 与时间线共用；“最近在日历上用过的板块”只存在界面状态里，不进数据和撤销历史。
- 撤销重做用现有的 `useUndoKeys`；输入框、文本框、选择框、可编辑元素里不响应任何快捷键。
- 视觉沿用全局页：画布底色 `--bg-canvas`、白色卡片加 `--shadow-card`、标题 `font-serif`；最小宽度 1024 像素；不做手机端、周视图、自动翻月、跨板块拖动。
- 打包后脚本压缩后不超过 200 KB；文字对比度达到 WCAG AA；`prefers-reduced-motion` 下没有多余动画。
- 约定式提交，提交信息末尾带 Co-Authored-By 行；先写失败的测试，再写实现；测试里用 `vi.useFakeTimers({ toFake: ['Date'] })` 并把系统时间固定在 2026-11-10 12:00，路由用 `window.location.hash` 设置；拖动测试用 `fireEvent.pointerDown/Move/Up`，网格尺寸通过给 `month-grid` 元素桩 `getBoundingClientRect` 提供（同 `features/timeline/drag.test.tsx` 的做法）。
- 每个任务结束时 `npm run lint && npm run typecheck && npm test` 全部通过。

## Review Focus

1. **拖动得出不合法的结果**（结束早于开始、不足 1 天、拖到网格外、拖动中被拖的项被撤销或删除、板块消失）：不写入数据、不报错（Task 4 纯函数，Task 10 页面）。
2. **编辑面板的定位**：阶段跨周有多段，面板只能贴着带 `data-testid="phase-<id>"` 的那一段；日期改到另一周、换板块、被拖动时，那一段会换成另一个元素，面板必须跟过去而不是停在已脱离页面的旧元素上（Task 6、7、10）。
3. **月份参数异常**（`2026-13`、`0000-01`、`1899-12`、`2101-01`、空串、`2026-1`、带斜杠）：回到当前月，不报错；翻到 1900 年 1 月和 2100 年 12 月时对应方向的按钮禁用（Task 1、5、7）。
4. **边界月份**：4 周的月份（2027 年 2 月）、6 周的月份（2026 年 11 月）、跨年（12 月到 1 月）、闰年二月，阶段跨月、跨年、跨 6 周，一天项目很多（Task 1、2、3）。
5. **单击与拖动不能混**：拖选后松手不能再触发一次“单击建节点”；单击已有项只选中和打开，不新建；拖动后没有残留的监听；键盘快捷键不被“+N 项”弹出层里的按键误触发（Task 8、9、10、11）。

### Task 1: 月份参数、翻月、月网格

**Files:**
- Create: `src/features/calendar/month.ts`
- Test: `src/features/calendar/month.test.ts`

**Interfaces:**
- Consumes: `toDay`、`fromDay`（`features/timeline/days`），`mondayOf`（`features/timeline/snap`）。
- Produces:
  - `interface MonthRef { year: number; month: number }`（`month` 为 1 到 12）；`MIN_YEAR = 1900`、`MAX_YEAR = 2100`。
  - `parseMonthParam(param: string | null, today: number): MonthRef`：严格匹配 `^\d{4}-(0[1-9]|1[0-2])$` 且年份在范围内才采用，否则取 `today` 所在的月。
  - `monthParam(ref: MonthRef): string`（`2026-11`）；`monthTitle(ref): string`（`2026年11月`）。
  - `shiftMonth(ref: MonthRef, delta: -1 | 1): MonthRef | null`：越过 1900-01 或 2100-12 返回 `null`；跨年正确。
  - `monthWeeks(ref: MonthRef): number[][]`：每周 7 个整日数，周一起；从包含当月 1 日的周一，到包含当月最后一天的周日。

  - `monthParam`、`monthTitle` 补零和文案：`{2026, 3}` → `'2026-03'`、`'2026年3月'`。
  - `shiftMonth({2026,12}, 1)` → `{2027,1}`；`({2027,1}, -1)` → `{2026,12}`；`({1900,1}, -1)`、`({2100,12}, 1)` 为 `null`。

**Interfaces:**

- Produces:
  - `const SLOTS = 3`
  - ```ts
    interface CalendarData { lanes: Lane[]; phases: Phase[]; milestones: Milestone[]; terms: Term[] }

  - 学期 `2026-09-01` 到 `2026-11-03`：第 1 周行 `startCol 0, endCol 6, labelled`；第 2 周行 `startCol 0, endCol 0, !labelled`。

### Task 3: 节点、“+N 项”和某天的全部项目

**Files:**
- Modify: `src/features/calendar/layout.ts`
- Test: `src/features/calendar/layout.test.ts`（追加）

**Interfaces:**
- Consumes: Task 2 的 `layoutMonth`、`BarSegment`、`CalendarData`、`SLOTS`。
- Produces:
  - ```ts
    interface DotItem { milestone: Milestone; col: number; slot: number }
    interface OverflowCell { col: number; count: number }
    // WeekLayout 增加：
    //   dots: DotItem[]        // 只含 slot < 3 且这一天没有被“+N 项”占用第 3 槽的节点
    //   overflow: OverflowCell[]
    ```
  - `type DayItem = { kind: 'phase'; phase: Phase } | { kind: 'milestone'; milestone: Milestone }`
  - `dayItems(day: number, data: CalendarData): DayItem[]`：这一天的全部阶段（`start <= day < end`）和节点，按板块 `order`，同板块阶段在前（按 `start`、`id`）、节点在后（按 `id`）。
  - 规则：节点在阶段排好之后，各取它所在那一天最靠前的空槽。某一天有项目落在槽 `>= SLOTS` 时，这一天的第 3 槽（槽号 2）改为“+N 项”（`overflow` 里记 `{col, count}`，`count` 是这一天槽号 `>= 2` 的项数），槽号 2 的色条在这些天不画（所以会被分成多段），槽号 `>= 3` 的不画。分段后 `labelled` 重新计算：给这个阶段**实际画出的第一段**。`startsHere`、`endsHere` 仍按真实起止判断。

  - 节点放在没有色条的那一天槽 0；放在已有 1 个色条的那一天槽 1。
  - 一周里 4 个阶段覆盖 11 月 9 日到 11 日（同周行 0 到 2 列）：槽 0、1 的色条照常，槽 2 的色条整体不画，`overflow` 为 `[{col:0,count:2},{col:1,count:2},{col:2,count:2}]`。

  - 一天只有 3 个项目（没有槽 `>= 3`）：不产生 `overflow`，第 3 槽的项目照常画。
  - `dayItems`：两个板块各有阶段和节点时，顺序是板块 1 的阶段、板块 1 的节点、板块 2 的阶段……；`end` 当天不含；节点只在它的日期出现。

### Task 4: 拖动的日期计算

**Files:**
- Create: `src/features/calendar/drag.ts`
- Test: `src/features/calendar/drag.test.ts`

**Interfaces:**
- Consumes: 无（纯函数）。
- Produces:
  - `const DRAG_THRESHOLD_PX = 4`；`exceedsThreshold(dx: number, dy: number): boolean`（`Math.hypot >= 4`）。
  - `interface GridRect { left: number; top: number; width: number; height: number }`
  - `dayAtPoint(rect: GridRect, weeks: number[][], x: number, y: number): number | null`：网格外（含恰好越过右、下边界）返回 `null`；每格宽 `width / 7`，每行高 `height / weeks.length`。
  - `createRange(anchorDay: number, currentDay: number): { start: number; end: number }`：`start` 是较小者，`end` 是较大者加 1（半开）。
  - `shiftRange(start: number, end: number, delta: number): { start: number; end: number }`：整体平移，长度不变。
  - `resizeRange(start: number, end: number, edge: 'start' | 'end', hoverDay: number): { start: number; end: number }`：拖开始端时 `start = min(hoverDay, end - 1)`；拖结束端时 `hoverDay` 是新的最后一天，`end = max(hoverDay + 1, start + 1)`，所以最短 1 天。

- [ ] **Step 1: 写失败的测试** `drag.test.ts`，断言：
  - `dayAtPoint`：矩形 `{left:100, top:50, width:700, height:500}`、5 周时每格 100 × 100；`(100,50)` 是第 1 行第 1 列；`(799,549)` 是第 5 行第 7 列；`(99,60)`、`(800,60)`、`(150,49)`、`(150,550)` 为 `null`；`(250,160)` 是第 2 行第 2 列（`weeks[1][1]`）。
  - `createRange(10, 14)` → `{10, 15}`；`createRange(14, 10)` → `{10, 15}`（反向）；`createRange(10, 10)` → `{10, 11}`。
  - `shiftRange(10, 20, 3)` → `{13, 23}`；`shiftRange(10, 20, -30)` 长度仍为 10。
  - `resizeRange(10, 20, 'start', 12)` → `{12, 20}`；`('start', 25)` → `{19, 20}`（最短 1 天）；`(10, 20, 'end', 14)` → `{10, 15}`；`('end', 3)` → `{10, 11}`；`('end', 19)` → `{10, 20}`。
  - `exceedsThreshold(3, 0)` 假，`(3, 3)` 真，`(0, 4)` 真。
